# QField Traccar Plugin

This [QField](https://qfield.org) plugin enables users to keep track of devices
registered on Traccar servers by through map canvas marker overlays.


# Installation

To install the plugin, [download the plugin from the releases page](https://github.com/opengisch/qfield-traccar/releases/tag/v1.0)
and follow the [plugin installation guide](https://docs.qfield.org/how-to/advanced-how-tos/plugins/#application-plugins).
